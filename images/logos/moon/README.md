# Drawings for the night mode button (moon, top right)

**Live on the site since 2026-11-08.** The three drawings here (1, 2, 3)
are the originals; the site uses small copies of them in the `site`
folder (96px tall, all three lined up on the same canvas), playing
1 2 3 2 1 2 3 … one step every half second.

To change the moon, upload new drawings here with the same names
(1, 2 and 3; any format, phone photos of paper drawings are fine) and
ask Claude to remake the small copies. The same cream fill and dark
outline work on both the light and the night background, so there's
no separate night version.

To upload: open this folder on github.com, then Add file › Upload files.
