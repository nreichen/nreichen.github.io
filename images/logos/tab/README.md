# Drawing for the browser tab icon (the "n")

**Live on the site since 2026-11-09.** `n.png` here is the original. The
icon files the site uses (`favicon.ico` and `apple-touch-icon.png` at the
top of the repository) are made from it by `tools/tab_icon.py`.

Its cream fill and thick dark outline read on both light and dark browser
tabs, even at 16 pixels, so there's no separate dark version.

To change it, upload a new drawing here named **n** (any format; a phone
photo of a paper drawing is fine) and ask Claude to remake the icons.
Tabs show it tiny, so keep it roughly square, bold and simple. Chrome
can't animate tab icons, so it's one drawing, not three.

To upload: open this folder on github.com, then Add file › Upload files.
