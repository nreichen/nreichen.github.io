# Drawing for the browser tab icon (the "n")

Upload one drawing here, named **n** (any format: .png, .jpg or .heic,
and a phone photo of a paper drawing is fine).

It replaces the placeholder "n" shown in browser tabs, bookmarks and
iPhone home screens. Tabs show it tiny, about 16 pixels square, so:

- Draw it roughly square, filling most of the space.
- Use a thick pen and keep it simple: thin lines and small details
  vanish at that size.
- Dark ink on plain white paper, or a drawing with a transparent
  background like the moon.

Claude crops it, removes the paper, and makes the icon files from it
(`favicon.svg`, `favicon.ico`, `apple-touch-icon.png` at the top of the
repository), checking that it still reads on a dark browser tab.

The tab icon can't animate in Chrome, so this is one drawing, not three.

To upload: open this folder on github.com, then Add file › Upload files.
